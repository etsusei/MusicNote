音乐拆轨最小运行版本（MP3 192 kbps）

使用（先选定音频，再以 --confirm 明确确认开始）：
python3 /Users/yao/Desktop/musicnote/work/run_separation.py "/音频完整路径/歌曲.mp3" --confirm --output-dir "/输出目录"

默认输出 /Users/yao/Desktop/musicnote/output。已有同名 MP3 或 mp3-export.json 时拒绝覆盖；下一首请指定新的输出目录。不加 --confirm 不执行解码或拆轨。默认处理整曲，不自动截取片段。
需要本机 Logic Pro 模型、Apple Silicon Metal GPU、Xcode 命令行工具、/opt/homebrew/bin/ffmpeg 与 ffprobe。普通本地终端可运行；受限沙箱需允许 GPU 访问。没有 GPU 时明确报错，不悄悄改用 CPU。

流程：音频临时解码为 44.1 kHz 双声道 → Core ML 六轨分离 → 临时浮点音频 → 全部轨统一衰减 → libmp3lame 192 kbps MP3 → 完整解码验证 → 发布成品。正常完成或可捕获错误后清理受控临时目录；编译模块缓存也自动清理。临时 WAV 不作为最终交付。试听及后续音频转 MIDI 使用输出 MP3；本版本不包含 MIDI 模型。
所有轨使用同一固定增益，不单轨归一化，不加限幅或音效。编码前目标峰值不高于 -1.5 dBFS，编码后检测峰值，必要时六轨一起进一步衰减。每次的增益和文件检查记录在输出 mp3-export.json。

六轨文件：01_vocals.mp3 人声；02_drums.mp3 鼓；03_bass.mp3 贝斯；04_guitar.mp3 吉他；05_piano.mp3 钢琴；06_other.mp3 其他。
