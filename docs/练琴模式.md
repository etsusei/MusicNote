# 练琴模式需求

版本日期：2026 年 11 月 13 日。状态：按文末的顺序实现中，第 1、2 步已完成。

电钢琴通过 MIDI 接 Logic 发声。练琴模式用来翻弹学习：把一段钢琴转成 MIDI，在 Logic 里校准，再回到 Musicnote 里看着下落音符、跟着原曲练。

## 流程

1. 导入歌曲，选取区间。
2. 确认 BPM 和拍点（可以手填，也可以跟着音乐点节拍）。
3. 拆轨，选钢琴轨，用 MuScriptor 转成 MIDI。
4. 导出到 Logic：原曲片段、钢琴分轨、MIDI 三个文件，起点一致。
5. 在 Logic 里对照钢琴分轨手动校准 MIDI，再从第 1 小节开头导出。
6. 把校准后的 MIDI 拖回 Musicnote。
7. 进入练琴页，配合原曲或分轨练习，也可以关掉伴奏。

第 1 到 3 步沿用现有流程，第 4 到 7 步是新增的。

## 已定事项

| 事项 | 决定 |
| --- | --- |
| 放在哪 | 做进 Musicnote，不做 Logic 插件，不另起一个 app |
| 代码组织 | 练琴是单独的模式和单独的模块，只复用 Core 和音频引擎，不碰和声分析的代码 |
| 琴声 | 从 Logic 出。Musicnote 只读电钢琴的 MIDI 输入，用来亮灯和判断对错 |
| 变速 | 用 Rubber Band 库（R3 引擎），源码直接放进仓库，README 注明 GPL |
| MIDI 回放音 | 默认关闭，用自带音色。不做发给 Logic 的路由 |
| 分手练习 | 第一版不做。以后做的话在 app 里分，不依赖 Logic 拆轨 |
| 片段长度 | 不考虑分段，整首歌也直接整段处理 |
| 界面风格 | 练琴页先用新风格，旧页面以后单独一个阶段再改。琥珀和冷白两套配色都做，可以切换，默认琥珀 |

## 第一版功能

### 打节拍测 BPM

加在现有的「确认 BPM」页面，原有的手填、加减、半速倍速、拍点偏移都保留。

- 原曲播放时点按钮或按键，按点击间隔算出 BPM，填进输入框。
- 点满 4 下开始出结果，点得越多越准。停顿超过 2 秒重新开始算。
- 结果取整到 0.5，之后还能在输入框里微调。
- 同时用点击的时刻算出拍点偏移。算完后节拍器继续响，听着不对可以再调。

### 导出到 Logic

入口在片段页的「练琴」标签。

- 一个按钮导出一个文件夹：`1 原曲.wav`、`2 钢琴.wav`、`3 MIDI.mid`。
- 三个文件起点相同。MIDI 里写的是确认过的 BPM。
- 在 Logic 里一起拖到第 1 小节开头就是对齐的。
- 文件的起点是片段开头之前最近的一条小节线，不够的部分垫静音。这样 Logic 的小节线正好落在音乐的小节上。片段本身从小节线开始时不垫。
- 同一个键在还没松开时又被弹了一次，导出时前一个音在重弹处结束。MIDI 文件本身分不清这种重叠的音该怎么配对。

### 导回校准后的 MIDI

- 把 Logic 导出的 `.mid` 拖进片段。
- 按文件里的速度信息把音符换算成时间，所以 Logic 工程用别的速度也没关系，只要音频还在第 1 小节开头。
- 和转录结果比对位置（转录是从分轨转出来的，等于和分轨比对）。整体错位时提醒，比如放到了第 2 小节，并可以一键移回去。
- 位置一致就直接导入；对不上太多音符时会问一下再导入。
- 踏板（CC64）一起读进来；鼓通道的音符不导入。
- MuScriptor 的原始结果和校准版分开存。再次导入会覆盖校准版，但保留历史版本。

### 伴奏

- 四选一：原曲 / 钢琴分轨 / 去掉钢琴的伴奏 / 关闭。
- 练琴页上有伴奏音量滑杆，播放中可以随时调，下次打开沿用上次的音量。
- MIDI 回放音打开时有自己单独的音量滑杆。
- 「去掉钢琴的伴奏」是其他五轨的混合。确认 MIDI 时，在删掉其他分轨之前自动合成一份（`backing.mp3`）。
- 以前做完的片段其他分轨已经删了，「练琴」标签里有「重新拆轨生成伴奏」，只生成伴奏，不动已有的分轨、MIDI 和和声。

### 练琴页

- 全屏。下方是横放的 88 键，音符从上方落下，落到琴键时对应的键亮起。
- 琴键上可以显示音名。
- 可以调提前多久看到音符（下落速度和缩放）。
- MIDI 里有踏板信息时显示踏板线。

### 界面风格

样稿：<https://claude.ai/artifact/Mq6v3EBYMfQcZHBHtYRa85>（私有链接）。

- 整屏暗底，不用描边和卡片，全页只有一个强调色。
- 两套配色可以切换：琥珀（暖灰底、象牙白琴键、琥珀色音符）和冷白（中性灰底、冷白琴键、蓝色强调）。
- 顶部一行是歌名、播放和速度、伴奏；第二行是进度条和 AB 循环；中间是下落音符；键盘贴着屏幕底边。
- 控件偏大，因为练琴时人离屏幕远。

### AB 循环

- 设 A 点和 B 点，循环播放这一段。
- 循环点吸附到小节线。
- 每次回到 A 之前有预备：提前一小节进入，或先打一小节拍。
- 衔接处音频做很短的淡入淡出。

### 实时变速

- 范围 0.5 到 1.0 倍，变速不变调。
- 播放中拖动速度条立即生效，速度平滑过渡，没有咔哒声。
- 下落音符、亮灯、AB 循环和伴奏始终同步。

### 读电钢琴输入

- 用 CoreMIDI 读电钢琴的按键，和 Logic 同时接收，互不影响。
- 按对的键亮一种颜色，按错的亮另一种。
- 有一个延迟校准项，用来抵消画面和声音的偏差。

### 快捷键

| 键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| `[` `]` | 设 A 点 / B 点 |
| `-` `+` | 减速 / 加速 |

## 第二版

- 等待模式：没按对就停住不往下走。
- 循环逐步提速：每弹对一遍自动加 5%，直到原速。
- 下落区上方显示和弦名称（复用已有的和弦分析）。
- 分手练习：在 app 里把音符分成左右手，可以只练一只手。
- 每一遍的命中率和快慢统计。

## 实现要点

- **代码位置**：不依赖界面的逻辑在 `Sources/MusicnotePractice`（读 MIDI 文件、往返 Logic 的时间换算、位置比对），页面在 `Sources/MusicnoteApp/Practice`。
- **真实片段检查**：`swift run MusicnoteChecks practice <数据目录> <片段 ID> <输出目录>` 对一个做完的片段跑一遍导出和导回。
- **一个时钟**：引擎用歌曲里的时间位置当时钟，播放速度只决定这个时钟走多快。画面和循环都看这一个时钟。
- **只有伴奏音频过 Rubber Band**：MIDI 回放音和节拍器按换算后的时间直接触发，不经过变速处理。
- **补偿延迟**：Rubber Band 实时处理有固定延迟，画面要扣掉这段延迟。
- **Rubber Band 接入**：用它的单文件编译方式，作为 SwiftPM 的 C++ 模块，不需要 Xcode。

- **不分段处理**：区间可以是整首歌，直接整段拆轨和转 MIDI，不做分段。转 MIDI 仍然用 MuScriptor medium。

## 建议的实现顺序

1. 打节拍测 BPM。
2. 导出到 Logic 的打包，导回 MIDI 并检查对齐，多存一份去掉钢琴的伴奏。
3. 接入 Rubber Band，引擎支持实时变速。
4. 练琴页：下落音符、键盘亮灯、伴奏切换、AB 循环、速度条。
5. 读电钢琴输入，显示对错，延迟校准。

每完成一步就提交并推送。
